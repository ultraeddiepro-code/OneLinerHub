# Vector One-Liners

## Sort Vector

```cpp
sort(v.begin(), v.end());
```

Sort vector ascending.

---

## Reverse Vector

```cpp
reverse(v.begin(), v.end());
```

Reverse vector elements.

---

## Maximum Element

```cpp
*max_element(v.begin(), v.end())
```

Get largest value.

---

## Minimum Element

```cpp
*min_element(v.begin(), v.end())
```

Get smallest value.

---

## Sum of Elements

```cpp
accumulate(v.begin(), v.end(), 0)
```

Calculate total sum.
