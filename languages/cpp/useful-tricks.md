# Useful Tricks

## Fast I/O

```cpp
ios::sync_with_stdio(false); cin.tie(nullptr);
```

Speed up input/output.

---

## Swap Values

```cpp
swap(a, b);
```

Exchange values.

---

## Lambda Function

```cpp
[](int a, int b){ return a < b; }
```

Anonymous function.

---

## Range-Based Loop

```cpp
for(auto &x : v)
```

Iterate through container.

---

## Size of Vector

```cpp
v.size()
```

Get number of elements.
