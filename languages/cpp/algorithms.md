# Algorithms

## Binary Search

```cpp
binary_search(v.begin(), v.end(), x)
```

Check if value exists.

---

## Count Occurrences

```cpp
count(v.begin(), v.end(), x)
```

Count occurrences of value.

---

## Find Element

```cpp
find(v.begin(), v.end(), x)
```

Locate an element.

---

## Next Permutation

```cpp
next_permutation(v.begin(), v.end())
```

Generate next lexicographical arrangement.
