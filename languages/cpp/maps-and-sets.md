# Maps and Sets

## Check Key Exists

```cpp
mp.count(key)
```

Returns 1 if key exists.

---

## Insert Into Set

```cpp
st.insert(x);
```

Insert value.

---

## Erase From Set

```cpp
st.erase(x);
```

Remove value.

---

## Frequency Counter

```cpp
mp[x]++
```

Count occurrences.

---

## Set Size

```cpp
st.size()
```

Number of unique elements.

---

## Access Value

```cpp
mp[key]
```

Get mapped value.
