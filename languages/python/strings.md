# String One-Liners

## Reverse String

```python
text[::-1]
```

Reverse a string.

---

## Title Case

```python
text.title()
```

Capitalize each word.

---

## Count Words

```python
len(text.split())
```

Count words in a string.

---

## Remove Spaces

```python
text.replace(" ", "")
```

Remove all spaces.
