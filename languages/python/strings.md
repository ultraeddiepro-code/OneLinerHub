# String One-Liners

## Reverse String

```python
text[::-1]
```

Reverse a string.

---

## Count Words

```python
len(text.split())
```

Count words in a string.

---

## Remove Spaces

```python
text.replace(" ", "")
```

Remove all spaces.

---

## Title Case

```python
text.title()
```

Capitalize every word.

---

## Check Palindrome

```python
text == text[::-1]
```

Check if a string reads the same forwards and backwards.

---

## Count Character Occurrences

```python
text.count("a")
```

Count occurrences of a character.
