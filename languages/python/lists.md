# List One-Liners

## Remove Duplicates

```python
list(set(lst))
```

Remove duplicate values.

---

## Sort List

```python
sorted(lst)
```

Return sorted list.

---

## Find Maximum

```python
max(lst)
```

Get largest value.

---

## Find Minimum

```python
min(lst)
```

Get smallest value.

---

## Flatten Nested List

```python
[item for sublist in lst for item in sublist]
```

Flatten a nested list.

---

## Sum List

```python
sum(lst)
```

Calculate total.
