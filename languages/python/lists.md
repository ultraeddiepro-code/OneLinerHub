# List One-Liners

## Flatten List

```python
[item for sublist in lst for item in sublist]
```

Flatten nested lists.

---

## Remove Duplicates

```python
list(set(lst))
```

Remove duplicates.

---

## Sort List

```python
sorted(lst)
```

Return sorted list.

---

## Find Maximum

```python
max(lst)
```

Get largest value.
