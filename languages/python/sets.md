# Set One-Liners

## Unique Values

```python
set(lst)
```

Remove duplicates.

---

## Intersection

```python
set1 & set2
```

Common elements.

---

## Union

```python
set1 | set2
```

Combine unique elements.

---

## Difference

```python
set1 - set2
```

Items present only in first set.

---

## Symmetric Difference

```python
set1 ^ set2
```

Items present in either set but not both.
