# Date Functions

## CAST

```sql
CAST(col AS DATE)
```

Converts values to date type.

---

## DATE_TRUNC

```sql
DATE_TRUNC('month', date)
```

Rounds dates to month boundaries.

---

## EXTRACT

```sql
EXTRACT(YEAR FROM date)
```

Gets a specific date component.

---

## DATEDIFF

```sql
DATEDIFF(end_date, start_date)
```

Calculates difference between dates.
