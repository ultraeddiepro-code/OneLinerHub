# String Functions

## TRIM

```sql
TRIM(name)
```

Removes spaces from both ends.

---

## UPPER

```sql
UPPER(name)
```

Converts text to uppercase.

---

## LOWER

```sql
LOWER(name)
```

Converts text to lowercase.

---

## SUBSTRING

```sql
SUBSTRING(name, 1, 3)
```

Extracts part of a string.

---

## CONCAT

```sql
CONCAT(first_name, ' ', last_name)
```

Combines strings.
