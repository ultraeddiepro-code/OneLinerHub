# Useful Tricks

## Run Command Every Second

```bash
watch -n 1 command
```

Repeat command every second.

---

## Command History Search

```bash
history | grep git
```

Find commands in history.

---

## Copy Output to Clipboard

```bash
cat file.txt | xclip -selection clipboard
```

Copy terminal output.

---

## Show Tree Structure

```bash
tree
```

Display directory hierarchy.
